# 轻舟自动化

一个面向电商卖家的自动化服务落地页，用来展示订单、报表、竞品、商品内容和客服自动化服务，并把潜在客户引导到免费流程诊断。

这是一个静态站点，不需要构建工具，也没有第三方运行依赖。

## 页面包含

- 明确的电商自动化服务定位
- 多平台订单报表、竞品监控、商品内容、评论分析等服务卡片
- 电商重复工作年度成本计算器
- 诊断、交付、交接三步合作流程
- 0 元诊断、订单报表自动化、电商运营系统化三档报价
- 常见问题与预约表单

## 本地预览

直接打开 `index.html` 即可。也可以使用任意静态文件服务器，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。
