# 轻舟自动化

一个可直接部署的自动化服务落地页，用来展示服务、计算重复工作的成本，并把潜在客户引导到免费流程诊断。

这是一个静态站点，不需要构建工具，也没有第三方运行依赖。

## 页面包含

- 明确的自动化服务定位
- 数据整理、线索调研、客户回复、跨工具连接等服务卡片
- 重复工作年度成本计算器
- 诊断、交付、交接三步合作流程
- 0 元诊断、轻量自动化、系统化交付三档报价
- 常见问题与预约表单

## 本地预览

直接打开 `index.html` 即可。也可以使用任意静态文件服务器，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 上线前修改

1. 打开 `index.html`，可以先使用 `data-github-url` 让访问者通过 GitHub 联系你。
2. 准备好公开邮箱后，在表单上补充 `data-contact-email="你的邮箱"`，页面会优先生成预约邮件。
3. 搜索“轻舟自动化”，替换成你的品牌名。
4. 根据自己的行业调整服务卡片、价格和常见问题。
5. 检查 `data-contact-email` 和 `data-github-url` 配置。

当前表单不会上传数据：配置邮箱时会生成预约邮件，未配置邮箱时会引导访问者前往 GitHub。如果希望直接收集客户资料，可以接入 Formspree、Tally、金山表单或自己的后端接口。

## 可以怎么变现

- 先用免费诊断获取潜在客户，再推销 699 元起的轻量自动化交付。
- 把计算器截图发给小商家，展示重复工作的年度成本。
- 把落地页作为报价单和案例展示页，发给现有客户与合作伙伴。
- 第一个案例完成后，在页面增加“节省时间 / 降低错误 / 增加线索”的真实结果。

## 部署建议

- 私有仓库：部署到 Vercel、Netlify、Cloudflare Pages 或 Render。
- 公开仓库：可以直接使用 GitHub Pages。

部署前请先补充真实联系方式，并对页面上的价格、承诺和案例做一次真实业务审核。
